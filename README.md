# quant-engineering

This repository tracks a **learning journey in algorithmic trading**: hands-on work **developing trading bots** and quantitative strategies.

The focus is on building real systems—backtests, signals, risk, and execution—with a **six-month objective** of reaching **over $3,000 per week** in sustainable bot-driven results (markets, capital, and discipline all matter; this repo is where the work lives).

## What’s here

- **`worldquantbrain/`** — BRAIN-style operators and simulation learning notes  
- **`optionVolatilityPricing/`** — options, volatility, and pricing study materials  

Add projects under this root as the journey grows.
